# 高低压柜报价文件整理

把图纸变成可报价的 Excel 材料清单。核心链路：**图纸 → 结构化提取 → 型号/尺寸归一化 → 价格库匹配 → 分项报价单**。

## 何时用这个 skill

- 用户给出 DWG / DXF / PDF 图纸，要求出材料清单或报价单
- 用户要求统计柜内元器件型号数量、柜体尺寸、铜排用量
- 用户要求把已有报价单核对/重构/补价

## 最新用户指定的报价排版（优先于下文旧版表格结构）

参照 `assets/九华新材_柜箱报价参考.xlsx`：所有柜、箱放在同一个工作表，按柜号分区；每台柜箱分别列出单台元件配置和独立报价，区块之间至少保留一整空行。每个区块标题注明柜箱名称、柜号和台数，明细数量明确为单台数量；单台报价与数量和项目总价分别核对，不把同型号不同柜箱误合并。每个区块依次列材料小计、制造费用、利润、税费、产品报价；价格未知留空，不编造。单台配置有差异时分别列区块。

参考表为 A–F 六列，区块首行 A:C 合并、D 为台、E 为台数、F 写“以下为单台配置”，其余行依次为序号、名称、型号规格、单位、数量、金额或留空；遵循参考表实际样式，不另加列或拆分工作表。原参考表没有区块间空白行，本要求明确增加空白行。下方历史的七列、备注空白及项目单一汇总指令与本条冲突时，以本条为准；不改动原参考文件。现有脚本尚未支持此格式，使用前须调整或另行制作并验证。


## 用户确认：今后识图与出表执行规则

每次分析图纸或生成材料单、报价单前，读取 `references/标号规则.md` 和适用模板；按其中规定的完整规格描述、单位与排版执行，不能缩写或只写电流、功率。软启动器采用规则中的完整技术描述，适配电机功率取图纸电机功率，设备标注功率与电机功率分别核对，不混同。接触器按标号规则中“旁路及交流接触器”描述，并按 `references/accessory_rules.json` 核对配套件，仅补差额。长文本必须换行、调整行高并检查显示完整。

图纸事实、技能预设要求和推算必须分清；未标明或无法可靠归属的型号、线圈电压、数量及规格不得编造，标为待确认并保留核对依据。技能标准描述不是图纸已确认事实。若现有脚本或模板不满足上述要求，先调整或另行制作，核对每柜、每项及最终表格后交付，不得声称现有脚本已经支持。

## 铁律（先读，别跳）

1. **绝不编造型号**。图纸上没写的型号一律留空并在 `待确认` 列标记 `缺型号`，不许按"经验"补一个看起来合理的。
2. **绝不编造价格**。价格只能来自 `price_db`（用户历史报价/采购价）。未匹配到的单价留空、整行标黄，输出到 `未匹配清单`。
3. **提取结果必须给人过目**。`extract.json` 和 `识别核对表` 是给人复核用的中间产物，不要跳过直接出报价单。
4. **铜排和柜体尺寸是推算值**，不是提取值。输出时必须带 `推算依据` 说明，并在表头标注"待复核"。

## 标准工作流

```
第0步  收集输入：图纸文件 + 价格库(price_db.xlsx) + 报价模板(可选)
第1步  分流     python scripts/dispatch.py <图纸目录或文件> --out work/
第2步  提取     python scripts/extract.py work/manifest.json --out work/extract.json
第3步  识别     python scripts/classify.py work/extract.json --out work/items.json
第4步  核价     python scripts/price_match.py work/items.json --db price_db.xlsx --out work/priced.json
第5步  出单     python scripts/build_quote.py work/priced.json --out 报价单.xlsx
```

`scripts/pipeline.py` 是一键串起 1-5 步的封装：

```bash
python scripts/pipeline.py --input <图纸或目录> --db price_db.xlsx --out 报价单.xlsx
```

## 三种图纸链路（自动分流）

| 类型 | 判定 | 提取器 | 准确率 | 说明 |
|---|---|---|---|---|
| DWG/DXF | 扩展名 | `extract_dxf` | 高 | 读 INSERT 块名+ATTRIB、TEXT/MTEXT、图层。**最可靠** |
| PDF 矢量 | PDF 内文字可选中 | `extract_pdf` | 中高 | PyMuPDF 抽文字+坐标，pdfplumber 抽表格 |
| PDF 扫描/图片 | 页面无文字层 | `extract_ocr` | 中 | 需 PaddleOCR，逐页 OCR，必须人工复核 |

DWG 无法用 Python 直接解析。本机已装 **LibreDWG 0.14**（`<工作区>/.workbuddy-ai/tools/libredwg/`），可直接转换：

```bash
cd <工作区>/.workbuddy-ai/tools/libredwg
./dwg2dxf.exe -o out.dxf in.dwg
```

AC1021(2007)/AC1032(2018) 实测可转，14MB DXF 约 2.5 秒解析完。转换时会刷 `Warning: Unstable Class object`，属正常，不影响文字提取。
备选：用户用 CAD 另存 DXF，或装 ODA File Converter。**不要尝试直接读 DWG 二进制**——R2007 以后数据段压缩，扫出来的全是乱码。

## 识别什么

### 识别优先级（重要，按此顺序）

**① 首选：电气原理图图块识别**

电气原理图/系统图上，每个元器件是一个图块（DXF INSERT）。这是最可靠的来源：

- **数量 = 图块引用次数**（一个符号就是一个元器件，不会说谎）
- **型号 = 就近匹配文字标注**（默认 1200 图纸单位半径内最近的含型号文字）
- **纯变比标注**（`2000/5`）没有型号前缀，按电流互感器处理，记为 `CT-2000/5`
- **只处理电气图层**：图层名含「系统」「原理」「控制」「电气」
- **排除平面图图层**：含「平面」「导线」「照明平面」「图框」「轴线」「COLUMN」「AXIS」「BXT」「文字」「DIM」

**归柜**：图块按最近的柜号标注坐标聚类，自动分到对应柜（柜号判定见下）。

实测（压滤机房 DWG）：电气图层 61 个图块 → 匹配 57 个（**召回 93%**），识别 17 种图块物料。

**柜号识别（重要）**：只有「两位以上字母 + 数字」才算柜号（`AP1`、`AL2`、`WD4`、`1#柜`）。必须排除 IEC 元件代号，否则 `KA2`（继电器）、`SB1`（按钮）、`DI1`（数字输入）、`L1`（相线）会被误当柜号，导致分柜错乱。排除名单见 `classify.py` 的 `_ELEM_CODE`。

**② 补充：图纸中的材料表**

图纸的「电气设备材料表」通常只到**柜级**（柜型、台数、尺寸），不含柜内元器件明细。
用途：补柜体、柜型、柜体尺寸，**不用于统计柜内元器件数量**。

**③ 兜底：全图文字扫描**

仅在图块识别无结果时启用（如纯 PDF 矢量图无图块）。数量靠启发式推断，置信度标 `low`，必须人工核对。

### 型号写法规范（重要）

材料清单里的型号**只写通用代号 + 规格参数，不写厂家系列**——实际订货可能换牌，型号里带厂家系列会锁死供应商。

| 类别 | 统一写法 | 转换示例（含 M/L/H 剥离） |
|---|---|---|
| 微型断路器 | `MCB-…` | `iC65N-C20A/2P` → `MCB-C20A/2P`；`DZ47-63 C16 2P` → `MCB-63 C16 2P`；`NXB-63 C16` → `MCB-63 C16` |
| 塑壳断路器 | `MCCB-…` | `CM3-250M/3300` → `MCCB-250/3300`；`NSX100N TM100 3P` → `MCCB-100N TM100 3P`；`CM5-250L/33002` → `MCCB-250/33002` |
| 框架断路器 | `ACB-…` | `CW3-1600/3` → `ACB-1600/3`；`E2N 2000` → `ACB-2000` |

**壳架电流后的分断等级字母 M/L/H 不写进型号**——那是厂家分断等级代号，订货换牌会变。改用「极限分断能力 Icu」字段统一注明，每张清单按此标注，避免等级写错或漏项：

| 断路器类别 | 极限分断能力 Icu | 判定依据 |
|---|---|---|
| 微型断路器 MCB | `10kA` | 固定 |
| 塑壳断路器 MCCB | `>50kA` | 固定（塑壳选高分断） |
| 框架断路器 ACB ≤2500A | `65kA` | 按额定电流，如 ACB-1600 |
| 框架断路器 ACB >2500A | `85kA` | 按额定电流，如 ACB-3200 |

**规格参数仍须保留**：壳架电流、脱扣器型号、极数、脱扣曲线。只去掉厂家系列名 + M/L/H 分断等级字母，分断能力改由 Icu 字段注明。

实现用**系列映射表**（`to_generic_model`）：先把厂家系列换成通用代号并剥掉 M/L/H，再用 `breaking_capacity()` 按上表算出 Icu 写进 `breaking_capacity` 字段。不能用正则替换——正则会吃掉壳架数字，`NSX100N` 会被替换成 `MCCB`，把关键的 `100N` 丢了。

品牌信息记在「品牌」列，不写进型号。

**型号串裁剪**（防止把回路标注吃进型号）：图纸一行里常把型号和回路号写在一起，如 `MCB-63A/3P 65A WK2`。型号向右扩展时遇到以下情况必须停：

- 回路标注：`WK2`、`WL1`（`W[KL]\d*`）
- 短回路号：`AJ1`、`KM2`（2 字母 + 1~2 位数字；`TM100` 是 3 位，属脱扣器型号，保留）
- 重复电流：`65A`（型号里已有 `63A`）
- 下一个型号：`CW3-1600/3`、`CH3N-63/3P`（另起一个元器件）
- DXF 的 GUID 块名（`a30-40cc-83dc-...`）整串跳过

`MCB-63A/3P 65A WK2` → `MCB-63A/3P`；`ACB-1600/3 CW3-1600/3` → 拆成两个型号（规范化后同为 `ACB-1600/3`，自动合并）。

### 四类元器件的标准写法（用户规则表，2026-11-01 定稿）

**变频器、马达保护器、软启动器、多功能电力仪表**的型号规格**不写品牌具体型号**，统一按技术要求描述填写（便于比价换牌）。完整规则见 `references/元器件物料表规则.xlsx`，程序内置在 `classify.py` 的 `STANDARD_MODELS`。

| 类别 | 型号规格（节选） | 备注列（配件说明，**不得并入型号**） |
|---|---|---|
| 变频器 | V/F控制。过载能力150%…防护等级IP20，柜内壁挂安装… | 一个变频器配4个中间继电器、2个保险丝、30个UK3.0端子、3个CJK22-DP指示灯、2个信号变送器 |
| 马达保护器 | 额定电流参考功率2.5倍…脱扣等级Class 20…结构形式分体式 | 一个马保配4个中间继电器、4个保险丝、25个UK3.0端子、2个CJK22-DP指示灯… |
| 软启动器 | 额定工作电压AC380V…旁路外置…防护等级IP20…RS485-Modbus | 一个软启动器配4个中间继电器、2个保险丝、30个UK3.0端子… |
| 多功能电力仪表 | 多功能表。3*AC400V三相四线…外径96*96…通信规约modbus rtu | 配4个熔断器 |

**铁律**：备注/说明是辅助填写型号用的，**禁止并入型号规格**。型号列只放技术要求描述，配件清单一律进「备注」列。长型号行会自动加高行高（最高 140pt）保证完整显示。

**变频器/软启动器的功率必须按图纸实际值**：型号开头自动加 `适配电机功率 XkW。`（X 从图纸标注的 `XkW` 提取，不写死）。图纸无功率标注时不加前缀，需人工补。

**注意图纸常用通用代号而非品牌系列**，型号库必须同时支持：

## 报价单结构（Excel 输出）

### 默认：所有柜箱合并一张标准分项报价表（用户指定格式）

**所有柜、箱的材料明细集中在同一张工作表，不按柜箱另建表或文件；保留各柜箱归属并核对数量，按项目汇总**，格式按 `assets/标准参考格式.xlsx` 1:1 复刻：

| 行 | 内容 | 样式 |
|---|---|---|
| 第1行 | `分项报价表`（A1:F1 合并） | 黑体 14 加粗，居中 |
| 第2行 | `项目名称：{项目}　　{柜号}`（A2:F2 合并） | 宋体 12 加粗，左对齐 |
| 第3行 | 表头：序号 / 名 称（元器件）/ 型 号 规 格 / 单位 / 数量 / 备注 / 金额 | 宋体 11 常规，白底 #FFFFFF |
| 第4行起 | 单一分组「元器件」（A:C 合并），柜体/风机/温湿度/其他辅材/铜排全部并入，序号连续 | 宋体 11，四边细实线 |
| 末段 | 材料小计 / 制造费 / 利润 / 税费 / 产品报价 | **项目汇总**，金额在 G 列 |

**备注列铁律（用户指定）**：备注列**一律为空，不写任何文字**——配件清单、金额、供应商、图块来源、识别依据全部不写。它只是辅助标记规格型号的空白列，程序固定输出空值。

**金额列（G）**：明细金额与汇总五项金额统一放 G 列，**绝不进备注**。

**行项口径（用户指定，必须遵守）**：

表格只有**一个分组「元器件」**，下列各项全部并入该分组、序号连续，**不再单列柜体/辅材/铜排分组**：

- **柜体**：作为整体**一行**，型号只写「**柜体尺寸 + 柜体型号**」（如 `800×1800×600 MNS抽屉式`），**不写含件明细**
- **柜体型号**（四类五种）：`XL-21` / `JXF` / `GGD` / `MNS抽屉式` / `MNS固定式`，由 `detect_cabinet_type()` 从图纸文字识别（MNS 默认抽屉式），可用 `--cabinet-type` 强制指定
- **柜体风机**：固定型号 **`ZL-805+200FZY2-D AC220V`**（以后不改）
- **温湿度传感器**：固定型号 **`TL5K-S1TC+温度传感器`**（以后不改）
- **其他辅材（总成）**：型号直接写 **`若干`**，不逐项描写（高压柜另加带电显示装置 `DXN-10`）
- **铜排**：主母排 + 分支排 + **接地铜排**（接地排计入铜排总量，不单列辅材）
- **元器件**：断路器、接触器、继电器、仪表、互感器、浪涌等图纸识别件

列宽 A6 B18 C31 D6 E6 F13（字符），行高 25pt，冻结 `A4`。型号列带极限分断（如 `MCB-16A/1P 10kA`）。

**柜体部件与铜排按柜数均摊**（数量、长度、重量、金额同步分摊），保证各柜独立成本加总等于总成本。分摊依据保存在表外复核资料中，备注保持空白。

单柜汇总口径：材料小计 = 本柜成本合计；利润 = 本柜加价部分；税费 =（材料小计 + 利润）× 13%；产品报价 = 三者之和；制造费留空由人工填。

**最新合表规则（2026-11-05）**：所有柜体、箱体材料明细放在一张工作表中，保持标准模板原有列、样式、备注及金额规则；通过原有表内适当的柜号标识区分归属，不新增列、不将不同柜箱的数量误合并。未归柜项目在同一工作表标记待确认。

**脚本限制**：现有 `build_quote.py`、`template_quote.py` 默认按柜拆表，尚不符合合表要求；不得直接把多表输出当作最终结果，应调整或另行处理并检查最终只有一张材料明细表。`--split-files` 不适用于默认交付。

## 价格库格式

`assets/price_db_template.xlsx` 是空白模板（含填写说明），复制一份填自己的历史价即可。

| 物料编码 | 类别 | 名称 | 型号 | 品牌 | 单位 | 单价 | 供应商 | 更新日期 | 备注 |
|---|---|---|---|---|---|---|---|---|---|

匹配策略：型号归一化（大写、去空格、统一 `×`/`*`/`x`、去多余连字符）后精确匹配 → 包含匹配 → 模糊匹配（相似度 ≥0.86）→ 名称+品牌。
柜体部件按**名称**匹配（型号列常是尺寸，不可靠）。铜排只匹配单位为 kg 的行，避免串到按米计价的辅材。

## 常见坑

- **同型号不同附件**：`NSX100N TM100 3P` 和 `NSX100N TM100 3P + 电操` 是两个价，别合并
- **数量单位**：图纸写"3P"是极数不是数量；"1用1备"是 2 台
- **柜体尺寸顺序**：国内习惯 `宽×高×深`，欧洲图纸可能是 `W×D×H`，看标题栏单位说明
- **铜排规格写法**：`TMY-80×10`、`TMY 80*10`、`80x10铜排`、`-80×10` 都要认
- **扫描件方向**：OCR 前先判旋转，横排图纸经常是旋转 90° 存的
- **GUID 块名当型号**：DXF 匿名块名形如 `a30-40cc-83dc-68ab58568b66`，会被 `A\d{3}` 匹配成 `A30` 再吃进整串，必须在 `find_models` 入口整串跳过
- **元件代号当柜号**：`KA2`（继电器）、`SB1`（按钮）、`DI1`/`AI1`/`AO1`（PLC 点）、`L1`（相线）都是「字母+数字」，会被柜号正则误抓，一张图能切出十几个假柜。必须用 `_ELEM_CODE` 黑名单排除
- **DXF 含非法代理字符**：部分 DXF 文字带未配对的 UTF-16 surrogates，`json.dump` 直接抛 `surrogates not allowed`，写 JSON 前必须 `encode('utf-8','ignore').decode()`
- **图纸标注叠写**：`ACB-1600/3 CW3-1600/3` 是一行两个型号（通用代号 + 原设计型号），应拆开、规范化后自动合并，不能当粘连整串保留
