# 统一入口及执行限制

运行 `python scripts/unified.py --status` 检查依赖；`--input 图纸` 检查分流。DWG须先转DXF并复核转换警告；OCR或输入提取失败时停止。图纸自动识别结果必须逐页逐柜人工核对。

`pipeline.py --input 图纸 --db 价格库.xlsx --out 报价单.xlsx` 输出标准单工作表，按柜分区、每柜一空行。柜数应在输入数据中明确；未归柜项目独立列待确认，不按柜数自动均摊。价格、数量或归属不完整时不显示完整合计；制造费未知时税费和产品报价留空。现有识图数量和配套件仍需人工核对，程序不保证逐项齐全。

铜排必须按设计或明确标为估算的真实分段提供。`python scripts/copper_segments.py 分段.json --out 铜排核对.json` 分别计算已录入分段的长度和理论净重；不自动生成未知段、损耗或采购量。可向 `price_match.py` 或 `pipeline.py` 传 `--copper-segments 分段.json`，将输入段计价；未标 complete 为 true 时自动生成未完成项。`unified.py` 暂不传递此参数，需要使用 pipeline 或 price_match。分段格式：

```json
{"voltage_class":"低压","complete":false,"segments":[{"id":"A1","cabinet":"RQ1","category":"主排","phase":"ABC","material":"铜","width_mm":40,"thickness_mm":5,"length_m":1,"pieces":3,"parallel":1,"status":"估算","basis":"示例假设，待核对"}]}
```

每段长度为单片展开长度；pieces必须包含实际相数和同类件数，parallel是每件并联片数，不能再乘相数。重复ID、缺失依据、零或负数、非低压输入会拒绝。complete=true仅代表操作者确认输入覆盖全部铜排；不能取代审图或电气校核。

以下工作尚未自动完成：图纸柜内铜排几何识别、成套元件及附件自动配齐与人工审图、柜体独立配置确认、按采购料长排样、公共母排按用户批准的方式分摊。FreeCAD和GElectrical仅检测，未自动调用；图形AI模型未接入。无价格库不能自动核价。
