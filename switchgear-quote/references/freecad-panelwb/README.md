# FreeCAD-PanelWB 重点参考

来源：https://github.com/QuakeString/FreeCAD-PanelWB ，作者 QuakeString，原项目许可证 LGPL-2.1-or-later，详见同目录 LICENSE。library.json 原样摘自该项目 parts/library.json；引用时请保留来源、版权和许可证。

原项目是 FreeCAD 控制柜设计工作台，可参考柜体、安装板、DIN 导轨、线槽、门面元件、设备布局与 BOM 之间的关系。原设备库为通用示例，宽高深、损耗、重量和 GEN 型号不是用户图纸或实物产品参数；只能作为分类与核对思路，禁止自动写入正式材料清单或当作实际型号、选型和计算依据。热计算是原项目提供的估算功能，未经工程验证不能作为验收结果。

本项目仅保存设备库和许可证作为资料参考，未安装 FreeCAD 或 PanelWB，未接入其设计、温升和出图功能。固定报价模板和格式不变。
