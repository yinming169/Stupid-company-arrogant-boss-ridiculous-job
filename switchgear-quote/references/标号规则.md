# 标号规则（最高优先级，所有出表必须遵守）

> 2026-11-05 更新：表格结构以 SKILL.md 最新报价排版和 assets/九华新材_柜箱报价参考.xlsx 为准；每柜箱独立区块和报价、区块间空行、同一工作表。下方冲突的旧表格结构不适用。

> 本文件是用户 2026-11-01 定稿的标号标准，经实验柜 `assets/标准样例_实验柜.xlsx` 逐项验证通过。
> **以后任何图纸、任何柜型、任何调用，型号写法一律以本文件为准，不得自行变更。**

---

## 一、表格结构（所有柜箱合并一张）

- **所有柜体、箱体材料明细合并在一个工作表，不按柜箱分表或分文件**。
- 保留各柜箱归属，使用既有表内标识，不增加列；未归柜项目在同一工作表标记待确认，不将不同柜箱数量误合并。
- 原有样式、7 列、备注空白和金额列规则不变。现有自动脚本仍会按柜拆表，须先调整或另行合并并检查。
- 严格 7 列：`序号 | 名 称（元器件） | 型 号 规 格 | 单位 | 数量 | 备注 | 金额`

| 行 | 内容 | 样式 |
|---|---|---|
| 第1行 | `分项报价表`（A1:G1 合并） | 黑体 14 加粗，居中 |
| 第2行 | `项目名称：{项目}　　{柜号}`（A2:G2 合并） | 宋体 12 加粗，左对齐 |
| 第3行 | 表头 7 列 | 宋体 11 常规，白底 #FFFFFF |
| 第4行 | 分组行「元器件」（A:C 合并，D 列单位「台」） | 宋体 11 |
| 第5行起 | 明细，序号连续（1、2、3…，不分组不跳号） | 宋体 11，四边细实线 |
| 末段 | 材料小计 / 制造费 / 利润 / 税费 / 产品报价 | 项目汇总，序号继续 |

- 列宽：A=6 B=18 C=31 D=6 E=6 F=13 G=11（字符）
- 行高：25pt；型号超过 60 字自动加高（最高 140pt）
- 冻结：`A4`

### 铁律

1. **备注列（F）永久空白，不写任何文字**——配件清单、金额、供应商、识别依据一律不写。
2. **金额只进 G 列**，明细与汇总五项都在 G 列。
3. **柜体 / 辅材 / 铜排不单列分组**，全部并入「元器件」一项，序号连续。
4. **项目汇总**：材料小计 → 制造费（留空）→ 利润 → 税费（13%）→ 产品报价。
5. 柜体部件、铜排按柜数均摊（数量/长度/重量/金额同步分摊）。

## 二、各类元器件的标准型号写法

### 1. 微型断路器

```
MCB-{电流}{极数} Icu≧10kA
```
示例：`MCB-63A/3P Icu≧10kA`、`MCB-32A/1P Icu≧10kA`

### 2. 塑壳断路器（两种，必须区分）

**配电保护型**：
```
MCCB/{极数}P In={电流}A。配电保护 Ue=AC400V,Ui=AC690V。Icu≧50kA。脱扣曲线 10-20倍In。固定式板前安装。
```

**电动机保护型**（马保配套开关，末尾追加辅助点）：
```
MCCB/{极数}P In={电流}A。电动机保护 Ue=AC400V,Ui=AC690V。Icu≧50kA。脱扣曲线 12-20倍In。固定式板前安装。含报警辅助点和开关辅助点。
```

> 判定：图纸/标注含「电动机保护 / 电机保护 / 马达保护」→ 电动机保护型，否则配电保护型。
> 辅助点写进**型号末尾**，不进备注。

### 3. 框架断路器

```
ACB-{电流}/{极数} Icu≧65kA      （额定电流 ≤2500A）
ACB-{电流}/{极数} Icu≧85kA      （额定电流 >2500A）
```
示例：`ACB-1600/3 Icu≧65kA`、`ACB-3200/3 Icu≧85kA`

### 4. 隔离开关

```
HR6-{电流}/{极数}P
```
示例：`HR6-100/3P`、`HR6-250/3P`、`HR6-400/3P`

### 5. 浪涌保护器

```
SPD-T{1|2|3}/SR/4P（配 SCB 后备保护）
```
- T1：低压进线柜
- T2：电容柜、动力柜、检修箱
- T3：室内照明箱

### 6. 熔断器

```
RT18-32X {电流}A
```
示例：`RT18-32X 6A`

### 7. 马达保护器（技术要求描述，不写品牌型号）

```
额定电流参考功率的2.5倍。电源电压：AC220V。含零序互感器。过载保护：指定脱扣等级（Class 20）。堵转保护：设定电流倍数（4-8倍In）和动作时间0.2s。不平衡/断相保护：设定不平衡度阈值（>40%）和动作时间。接地/漏电保护：设定动作电流值（0.1A,0.3A,1A）和时间。欠载保护：设定电流百分比（40%In）和动作延时。控制输出：继电器输出容量（用于控制接触器），几组常开/常闭点。通信接口：Profibus-DP。显示与操作：本地数码管/LCD显示单元，带按键编程。模拟量输出：4-20mA电流输出，对应实际电流。故障记录：记录历史故障信息。结构形式：分体式（显示单元与电流互感器分离）。
```


### 旁路及交流接触器（用户确认的描述要求）

规格应完整体现图纸可确认的额定电流、极数、线圈电压、使用类别及型号；缺少的参数标为待确认，不按经验补值。按配套件规则，每只接触器配置三常开两常闭（3NO+2NC）辅助触点及两只指示灯，先与图纸和已有清单核对，只补差额，避免与另列附件重复计数。辅助触点可在接触器规格中注明配置要求，但如果作为独立物料计价，只能计一次。图纸仅给出电流时不能仅写“185A”作为完整规格。

示例（仅表示 RQ 图纸的待复核候选，不是通用固定型号）：`额定电流185A（图示，待复核）。辅助触点3常开+2常闭。线圈电压、使用类别及具体型号待确认。` 不得把示例的185A用于其他回路。
### 8. 中间继电器

```
MY4N{AC230V|DC24V}+底座
```
示例：`MY4NAC230V+底座`、`MY4NDC24V+底座`

### 9. 按钮 / 指示灯 / 转换开关 / 电位器

| 类别 | 写法 | 示例 |
|---|---|---|
| 按钮 | `CJK22-P` | `CJK22-P` |
| 指示灯 | `CJK22-DP` | `CJK22-DP` |
| 万能转换开关 | `LW139A-04162` | 每个控制箱都有 |
| 电位器 | `LA42DWQ-22 5K` | 每个变频器配一个 |

### 10. 多功能电力仪表（技术要求描述）

```
多功能表。3*AC400V三相四线，辅助电源AC220V。壁挂安装，外径96*96，安装开孔91*91。全电量测量（电压、电流、有功功率、无功功率、功率因素等）。采样精度0.5级，数据采集完整性率≧99%。通过酸雾实验并提供型式试验报告复件。通信规约modbus rtu。
```

### 11. 电流互感器

```
BH-0.66Ⅱ
```
孔径按开关电流：400A-100A→30mm；16A-100A→20mm；630A→40mm；800-1250A→50mm；1600-2500A→80mm；3200-6300A→125mm

### 12. 电子表 / 温度控制器 / 信号变送器

| 类别 | 写法 |
|---|---|
| 电子表 | `PZ96 4-20mA输入` |
| 温度控制器 | `TL5K-S1TC+温度传感器` |
| 信号变送器 | `BM-DI/II AC230V 1路4-20mA输入 2路4-20mA输出` |

### 13. 软启动器（功率按图纸实际值）

```
适配电机功率 {X}kW。额定工作电压：AC380V（常规）。控制电源：AC220V/AC380V/DC24V。结构形式：旁路外置。防护等级：IP20（柜内）。安装方式：柜装式IP3X。启动方式：电压斜坡/限流启动/转矩控制。停车方式：自由停车/软停车/泵控停车（防水锤）。模拟量：4～20mA（调速/限流）。通讯接口：RS485-Modbus。过流、过载、缺相、相序保护。过压、欠压、过热保护。堵转、短路、三相不平衡保护。本地显示面板。
```

### 14. 变频器（功率按图纸实际值）

```
适配电机功率 {X}kW。V/F控制。过载能力150%，持续时间60s。额定输入输出电压/频率：AC 0-400V三相电压，频率0~60Hz。绝缘电压AC690V。二次控制回路工作电压AC220V。电机调速范围0-6000转。防护等级：IP20，柜内壁挂安装。选配2路4-20mA输入信号，选配2路4-20mA输出信号。选配操作器柜门嵌入式套件+中文液晶面板。
```

> `{X}` 从图纸标注的 `XkW` 提取，不写死。图纸无功率时人工补。

### 15. 端子

```
UK3N
```

### 16. 柜体

```
{柜型} {宽}×{高}×{深}
```
示例：`MNS抽屉式 800×1000×2200`

**柜型只有五种**：`XL-21`、`JXF`、`GGD`、`MNS抽屉式`、`MNS固定式`

### 17. 柜体风机（固定型号，不再变更）

```
ZL-805+200FZY2-D AC220V
```
**数量：2 套/柜**（规则表：一台柜子 2 只）

### 18. 温湿度传感器（固定型号，不再变更）

```
TL5K-S1TC+温度传感器
```

### 19. 其他辅材（总成，合并一项）

```
若干
```
含：母线框、绝缘子、热缩管、行线槽、标牌、紧固件、照明灯、门开关、加热器等，**不逐项描写**。

### 20. 铜排（按额定电流选规格）

| 电流范围 | 规格 |
|---|---|
| ≤250A | `TMY-30×4` |
| ≤400A | `TMY-40×5` |
| ≤630A | `TMY-50×5` |
| ≤800A | `TMY-50×6` |
| ≤1000A | `TMY-50×10` |
| ≤1250A | `TMY-80×8` |
| ≤1600A | `TMY-80×10` |
| ≤2000A | `TMY-100×10` |
| ≤2500A | `TMY-125×10` |
| ≤3200A | `TMY-2×(125×10)` |

- 主母排按**框架断路器（进线）**额定电流选，不能用支路 `In=` 标注
- 分支排按回路电流选
- 接地铜排固定 `TMY-30×4`，**计入铜排总量**，不单列辅材
- 图纸标注了规格时优先用图纸规格

## 三、金额口径

| 项 | 计算 |
|---|---|
| 材料小计 | 项目成本合计（元器件 + 柜体 + 辅材 + 铜排） |
| 制造费 | 留空，人工填 |
| 利润 | 项目加价部分（售价 − 成本） |
| 税费 | （材料小计 + 利润）× 13% |
| 产品报价 | 材料小计 + 制造费 + 利润 + 税费 |
