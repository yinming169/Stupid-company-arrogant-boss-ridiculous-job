## 一、电压降计算

### 电压降公式

```
ΔU% = (ΔUM + ΔUN) / U × 100%
```

- ΔUM：电动机（或负载）回路电压降（V）
- ΔUN：中性线（或配电设备）电压降（V）
- U：额定线电压（V）

### 计算范例（资料3 p256）

**工况**：
- 线路：电缆 50mm²，长度 50m
- 运行时：电流 120A，cosφ=0.8
- 起动时：电流 600A，cosφ=0.35
- 电压：400V

**运行时电压降**：
```
ΔU% = (4.5 + 6) / 400 × 100% ≈ 2.6%   ← 合格（<8%）
```

**起动时电压降**（电流增至 1500A，放大 1.5 倍）：
```
ΔU% = (22.5 + 1.5×6) / 400 × 100% = 7.88%   ← 接近极限（8%）
```

> **结论**：建议电缆由 50mm² 改为 75mm²，降低起动压降。

### 电压降限值（GB 50052 / GB 50054）

| 回路类型 | 允许压降 |
|---|---|
| 电动机主回路（正常运行） | ≤5% |
| 电动机起动时 | ≤15~20%（个别 ≤30%） |
| 一般照明 / 配电 | ≤3%~5% |
| 应急 / 消防 | ≤5% |

> 常用工程判断：**≤8% 可接受**，但越大起动越困难、发热越多。

## 二、电缆阻抗对短路电流的限制

### 原理

短路电流从变压器流出，经过电缆到达末端，电缆阻抗会显著限制短路电流：

```
I_末端 < I_始端
```

### 计算范例（资料3 p256）

**工况**：
- 变压器：2000kVA，阻抗 Ud=6%
- 一级母线短路电流：I = S / (√3 × U × Ud%) = 2000×10³ / (1.732×400×0.06) ≈ 48.1kA

**电缆 3×150mm²，长度 30m**：
- 查表4-6（电缆两端短路电流表）：始端 50kA → 末端 38kA

**结论**：末端断路器 QF3 的 Icu 只需 > 38kA，不必按 48kA 选。

## 三、变压器短路电流估算（快速）

| 变压器容量 (kVA) | 阻抗 Uk% | 低压母线短路电流 (kA) |
|---|---|---|
| 630 | 4% | ~22.7 |
| 800 | 6% | ~19.2 |
| 1000 | 6% | ~24.1 |
| 1250 | 6% | ~30.1 |
| 1600 | 6% | ~38.5 |
| 2000 | 6% | ~48.1 |
| 2500 | 6% | ~60.1 |

> 公式：Isc ≈ S(kVA) / (1.732 × 0.4 × Uk%)  [单位：A，需转 kA]

### 常见阻抗
- 干式变压器：Uk% = 4%~6%（小容量偏低）
- 油浸式：Uk% = 4%~5.5%
- 整流/特殊变压器：可能到 8%~10%
