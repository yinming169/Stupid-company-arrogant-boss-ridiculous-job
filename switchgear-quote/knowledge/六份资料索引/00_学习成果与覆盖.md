# 六份资料学习成果与覆盖说明

本文件记录可溯源的学习成果和检索范围；仅使用列明的原PDF页码，不把OCR、书籍全部处理或目录检索说成已逐页审核。原件存放在本备份 `../source_books/`，与用户提供的六份文件SHA-256一致；版本标识见数据库 books 表。页码均为PDF阅读器从1起计，纸面页码仅为附注。

## 索引及运行
- 运行 `python scripts/book_index.py search 接触器 --book 资料3 --limit 10`。多个关键词空格分开时按同页同时出现检索；适合汉字短语，不支持跨页语义搜索。可通过 `python scripts/book_index.py build` 从备份中的文字/OCR重建；构建依赖pypdfium2。source 标明文字库或OCR，多个来源可能同页重复，不能按命中数统计设备。
- 上述相对命令应在本 skill 目录执行并使用有效的 Python。本机 `python` 可能指向 Windows 应用商店占位程序；如无法执行，可在 PowerShell 使用当前 Codex 自带解释器，例如：`$env:PYTHONUTF8='1'; & 'C:\Users\Administrator\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' 'D:\switchgear-quote-full-backup\skill\scripts\book_index.py' status`。其他电脑应改为其实际 Python 路径；构建时另需安装相应依赖。
- 原始文字、已有OCR和本次生成的OCR都只是定位线索；数字、表格、公式、型号及图形应回原PDF验证。手册中旧产品、旧标准只作历史参考；实际引用前查官方标准有效状态、合同及厂家资料。
- 用户的表格格式、规则标号是输出偏好；技能模板中的参数不是图纸事实，选型和配套不得凭经验补充。

## 质量核查及可复现性
- 运行 `python scripts/book_index_check.py` 核查本次三个补充OCR区间的文件数、索引页数及页码范围；运行 `python -m unittest discover -s tests -v` 执行索引、材料规则及算例测试。通过仅验证覆盖、数据一致性和算例，不验证OCR准确率或工程结论正确性。
- 来源SHA-256、页数及索引覆盖见 `来源文件与覆盖清单.json`；`主题页码线索.csv`是关键词生成的主题页码表，同一页多来源可能重复、存在误检漏检。
- OCR脚本与运行依赖放在本skill内，来源PDF仍在同一备份的 `source_books/`；如迁移文件夹，应保留 `skill/` 与 `source_books/` 和原 `knowledge/` 的相对位置。旧版知识库原始文字仍在备份的 `knowledge/`，本skill里的SQLite提供离线检索；完整重建索引依赖这些原始文字和OCR目录。
