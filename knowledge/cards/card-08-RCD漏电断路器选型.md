## 一、剩余动作电流（IΔn）选择

| 应用场合 | 动作电流 | 动作时间 | 标准依据 |
|---|---|---|---|
| 直接接触防护（插座、手持电动工具） | 30mA | ≤0.1s | IEC/GB 标准强制 |
| 间接接触防护（固定设备外壳） | 100mA | ≤0.3s | 第一级后备保护 |
| 电气火灾预防（总配电柜） | 300mA | 延时型（S型） | GB 50054 要求 |
| 分级总保护（防越级） | 300mA~1A | 延时 0.3~0.5s | 与第二级配合 |

> **关键原则**：直接接触防护必须用 ≤30mA 瞬动型；总配电柜用 300mA 延时型（S型），避免越级跳闸。

---

## 二、分级漏电保护配置（两级配电范例，资料3 图3-55）

```
总配电 A 级：延时型 RCD（如 300mA / S 型）
   │
   └── 分配电 B 级：瞬动高灵敏 RCD（如 30mA / 0.1s）
```

| 级别 | 剩余电流 | 动作特性 | 位置 |
|---|---|---|---|
| A 级（上级） | 300mA | 延时（S型） | 总开关 / 进线柜 |
| B 级（下级） | 30mA | 瞬动 | 终端箱 / 插座回路 |

> **时间配合**：上级延时 ≥ 0.3s，下级瞬动 ≤ 0.1s，时间差 ≥ 0.2s，保证选择性。

### 脱扣特性标识

| 标识 | 含义 | 适用负载 |
|---|---|---|
| B | 对低感性和无冲击电流的配电系统保护 | 纯阻性负载、照明 |
| C | 对感性负荷和高感照明系统保护 | 一般配电、荧光灯 |
| D | 对高感性负荷和较大冲击电流保护 | 变压器、电机、电焊机 |

> **报价口诀**：照明/插座用 C 型；电机/变压器用 D 型；纯阻性用 B 型。

## 四、RCD 选型禁忌

| 错误 | 后果 |
|---|---|
| 总开关用 30mA 瞬动 RCD | 一处漏电全楼停电，无选择性 |
| 上级用瞬动、下级用延时 | 越级跳闸，上级先动作 |
| 变频器/整流负载前端加 RCD | 高频泄漏电流导致误动，应用 RCD 专用型（A型/Type B） |
| 三相负载用 1P RCD | 失去保护，只能断相线 |
| TT 系统不装 RCD | 接地故障无保护，触电风险 |

## 五、T 型 RCD（特殊场合）

| RCD 类型 | 适用 |
|---|---|
| AC 型 | 普通交流漏电（正弦波） |
| A 型 | 交流 + 脉动直流（含半波整流负载） |
| F 型 | A 型 + 变频/调光负载 |
| Type B | A 型 + 平滑直流（充电桩、光伏、变频器输出端） |

> 充电桩、光伏逆变器、变频器输出端必须用 **Type B**（或 A 型 + 专用滤波）。

## 六、报价应用

| 场景 | 配置建议 |
|---|---|
| 住宅楼总配电 | 300mA 延时型（S）总保 + 30mA 每户 |
| 工厂车间 | 300mA 总保 + 100mA 分区 + 30mA 插座 |
| 医院/学校 | 300mA 总保 + 30mA 末端（更高可靠性） |
| 充电桩配电 | Type B RCD，不可普通 AC 型 |
| 变频器柜 | A 型或 F 型 RCD，或取消 RCD 改绝缘监测 |
