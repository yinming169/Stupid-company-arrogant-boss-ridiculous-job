### 资料3 已提取的实用内容

**① 电动机直接起动判据（式 5-16，书页 295）**

```
P_NM = 0.133 × (ΔU% / U_Tr − β) × S_Tn
```
- `P_NM` 电动机输出功率（kW）
- `ΔU%` 变压器输出电压允许压降（一般取 10%）
- `U_Tr` 变压器阻抗电压百分数（如 4%、6%）
- `β` 电动机起动前变压器已带的其他负荷占容量比例
- `S_Tn` 变压器容量（kVA）
- 取 `cosφ_NM = 0.8`，`K_m = 6`（起动电流倍数）

**用途**：判定电机能否直接起动。算出来 `P_NM` 小于实际电机功率 → 必须配软启动或变频，直接影响报价。

## 一、配电装置分类（定柜型用）

### 1.1 按电压等级
- **高压柜**：10kV / 35kV，KYN28（中置式）、XGN（箱式）、环网柜
- **低压柜**：0.4kV，GGD / GCK / GCS / MNS / XL-21 / PZ30

### 1.2 按功能
进线柜、出线柜、母线联络柜、电容器补偿柜、仪表柜、动力配电箱、照明配电箱、控制箱、双电源切换箱

### 1.3 按安装方式
- **固定式**：元件固定安装，检修需停电，代表 GGD。便宜、回路少
- **抽出式（抽屉式）**：功能单元可抽出，不停电检修，代表 GCK/GCS/MNS。贵、回路多

### 1.4 按标准化
成套型（有统一型号）、非标准型（配电箱、配电板，无统一型号，分暗装/明装）

## 三、选型规则（可直接执行）

### 3.1 低压断路器

**选型五步**
1. 类型：600A 以下多用塑壳式，以上多用框架式（万能式 630~6300A）
2. 额定电压 ≥ 线路额定电压；欠压脱扣器额定电压 = 线路额定电压
3. 额定电流及过流脱扣器额定电流 ≥ 线路计算电流
4. 极限分断能力 > 线路最大短路电流有效值
5. 上下级保护特性协调：下级特性曲线位于上级下方且不相交；长延时脱扣电流 < 导线允许持续电流

#### 3.1.1 选择要点（资料1 p385，OCR 版）

1. 额定工作电压 ≥ 线路额定电压
2. 额定电流 ≥ 线路计算负载电流
3. 额定短路通断能力 ≥ 线路可能出现的最大短路电流
4. **线路末端单相对地短路电流 ≥ 1.25 × 脱扣器整定电流**
   - 不满足时：选单相接地保护断路器（如 DW16 型），或在零线装电流互感器，或采用带零序 CT 的线路/漏电继电器；变压器中性点必须接地
5. 欠电压脱扣器额定电压 = 线路额定电压（是否带延时按场合定）
6. 分励脱扣器额定电压 = 控制电源电压
7. 电动操作机构额定电压 = 控制电源电压
8. **母联断路器必须选可在下方进线的型号**
9. 各级断路器过电流脱扣器整定值和延时应符合选择性配合
10. 电动机保护断路器的瞬时动作电流要考虑电动机起动条件（种类、起动电流倍数、起动时间）

#### 3.1.2 额定电流确定

```
IN.OF ≥ Ica      IN.OF = 壳架等级额定电流（塑壳/框架能装的最大脱扣器额定电流）
IN.OR ≥ Ica      IN.OR = 过电流脱扣器额定电流
                 Ica   = 线路计算负荷电流
```

#### 3.1.3 脱扣器整定（资料1 p386-387）

**① 电动机保护用**

| 脱扣器 | 整定式 | 说明 |
|---|---|---|
| 热（长延时） | `1.1 IN ≥ Iop ≥ I` | IN 电机额定电流，I 正常工作电流；作过负荷保护 |
| 瞬时（电磁） | `Iop ≥ Krel × Ist` | Ist 起动电流；**Krel = 1.35**（动作时间 >0.02s）、**Krel = 1.7~2**（DZ 型等 <0.02s） |

**② 配电线路用**

| 脱扣器 | 整定式 | 说明 |
|---|---|---|
| 瞬时 | `Iop3 ≥ Krel3 × [I′st1 + Ica(n−1)]` | **Krel3 = 1.2**；`I′st1 = 2 × Ist`（最大一台电机的全起动电流，含非周期分量）；`Ica(n−1)` 为其余负荷计算电流 |
| 短延时 | `Iop2 ≥ Krel2 × [Ist1 + Ic(n−1)]` | **Krel2 = 1.2**；短延时时间 0.1/0.2/0.4s，**上下级时间差 0.1~0.2s** |
| 长延时 | `Iop1 ≥ Krel1 × Ica` 且 `Iop1 ≤ Ial` | Ial 为导线允许载流量，防止电缆过热 |

**选择性补充**：选择型断路器瞬时脱扣整定值还要躲过下一级开关所保护线路故障时的短路电流；非选择型只需躲过本回路尖峰电流，且尽量整定小一些。

#### 3.1.4 分断能力三个指标（资料1 p380）

| 指标 | 含义 | 关系 |
|---|---|---|
| Icu | 极限短路分断能力 | 试验顺序 O—CO（断—通断） |
| Ics | 额定运行短路分断能力 | 试验顺序 O—CO—CO；Ics 可取 25%/50%/75% Icu |
| 额定短路接通能力 | 峰值耐受 | Ics ≤3kA 时 ≥1.42Ics（cosφ=0.9）；3~6kA 时 ≥1.53Ics（cosφ=0.7） |

**断路器分类**：A 类非选择型、B 类选择型（B 类有长延时+短延时+瞬时，短延时 ≥0.05s）。

**结构**：主触头（银/银基粉末冶金）+ 弧触头（铜钨/银钨/铜石墨）+ 副触头（老产品）。
**单/双断口分界**：额定电流 <1000A 用单断口，≥1000A 用双断口桥式触头。

**脱扣曲线选择**
- 照明/配电：C 型（瞬时 6~20 倍 In）
- 电动机保护：D 型或电动机保护型（瞬时 10~20 倍 In）
- 配电保护：10~20 倍 In；电动机保护：12~20 倍 In（见用户物料表规则）

### 3.2 交流接触器

**电流估算（380V 三相）**
```
额定电流 ≈ 2 × 电动机功率(kW)
精确式：IN ≥ PN / (√3 · UN · cosφ · η) × K     K = 1~1.4
```

**使用类别**
| 类别 | 用途 | 通断能力 |
|---|---|---|
| AC-1 | 无感/微感负载（电阻炉） | 通断额定电流 |
| AC-3 | 一般任务，中小功率笼型电机 | 接通 6 倍、分断额定电流 |
| AC-4 | 重任务，大功率频繁启停、反接制动 | 通断 6 倍额定电流 |

- 控制**电容器或白炽灯**：冲击电流可达额定几十倍 → 选 AC-4；若用 AC-3 须降容至额定功率的 **70%~80%**
- 有反接制动时选大一级
- 线圈电压必须与控制电路一致（常用 AC220V / AC380V / DC24V）
- 常用电流等级：5 / 10 / 20 / 40 / 60 / 100 / 150 / 250 / 400 / 600A
- 通断能力 = 额定电流的 5~10 倍，超出部分由断路器/熔断器承担

### 3.3 热继电器（电热继电器）

- 额定电流按电动机额定电流选；**过载能力差的电机取 60%~80%**
- 不频繁启动、启动电流 6 倍 In、启动时间 ≤6s → 可按额定电流直接选
- 三角形接法电机：三相热继电器同时具备过载 + 断相保护；两相结构（JR1/JR2/JR0/JR15）**不能**用于三角形接法的断相保护
- **只保护长期过载，不保护短路和瞬时过载**
- 可逆运行、频繁通断的电机不宜用热继电器，改用埋入式温度继电器或过流继电器
- 整定电流 = 电动机额定电流（可调旋钮对准刻度）

### 3.4 熔断器

**熔体额定电流 Ire 计算**

| 保护对象 | 计算式 | 说明 |
|---|---|---|
| 照明、电热设备 | Ire ≥ Ie | 负载电流稳定 |
| 单台长期工作电机 | Ire ≥ (1.5~2.5) Ie | 轻载/短时启动取 1.5，重载取 2.5 |
| 频繁启动电机 | Ire ≥ (3~3.5) Ie | 考虑频繁启动发热 |
| 多台电机干线 | Ire ≥ (1.5~2.5) Iemax + ∑Ie | Iemax 为最大一台，∑Ie 为其余之和 |

- 熔断器额定电流 ≥ 熔体额定电流（同一壳架可装多种熔体）
- 上下级配合：上级熔体比下级大 **1~2 个级差**，防越级熔断
- 常用：RT18-32（32A 壳架）、RT16、RT23、RL1、RL6

### 3.5 中间继电器

- 触头容量 5~10A，动作时间 ≤0.05s，触头对数可多至 6 对
- 线圈额定电压必须与控制电路电压一致
- 线圈电压 ≠ 触头额定电压，两者可相同也可不同，别混淆
- 常用：MY4N（AC230V / DC24V）、RXM、CR-M、JZ7、HH5

### 3.6 按钮与指示灯

- 尺寸 φ22mm 最常用（另有 φ12/16/25/30）
- 颜色规范：
  - **急停 / 应急断开：必须红色**
  - 启动/接通：白、灰、黑（优先白），允许绿，**不允许红**
  - 停止/断开：黑、灰、白（优先黑），不允许绿
  - 复位：蓝、白、灰、黑
- 常用型号：CJK22-P（按钮）、CJK22-DP（指示灯）、LA38、LAY3、XB2

### 3.7 开关电源

- 工作在 **50%~80%** 负载区间最可靠
- 功率 ≥ **1.15 ×** 负载总功率
- 优先选标准多路输出共地电源

### 3.8 电流互感器

- 准确等级：计量用 0.5 级，测量用 0.5/1 级，保护用 5P/10P
- 变比按回路计算电流选，常用 100/5、200/5、400/5、800/5、1000/5、2000/5、3000/5

## 五、影响报价的安装与工艺要求

摘自手册1（定性，数值作废）：

- 低压电器应**垂直安装**，倾斜不超过 5°；螺栓固定，不得焊接
- 电源线接固定触点（上端子进线、下端子出线），隔离开关严禁反接
- 金属外壳、支架必须接地（接零）
- 不同相间最小净距：500V 及以下、500–660V 有明确规定（数值见标准，本手册已损坏）
- 主母线两绝缘框间距 1000mm 时，中间应加支撑绝缘子或绝缘板，提高动热稳定
- 母线搭接面清理后涂导电膏或中性凡士林再紧固
- 抽屉式结构须检查一、二次接插件插接可靠性、机械/电气联锁有效性
- 运行前检查：漆膜、元件型号与图纸一致性、辅助触点通断、二次线编号、互感器变比与极性、保护整定值、绝缘电阻与耐压

## 六、选型通用原则（手册1 框架）

### 6.1 按正常工作条件
1. 额定电压匹配回路标称电压，额定频率匹配
2. 额定电流 ≥ 回路最大稳定负荷电流；环境温度高于 40℃ 需按公式降容修正，高于 60℃ 不得使用
3. 切断负荷电流的电器（刀开关）校验断开电流
4. 接通/断开启动峰值电流的电器（接触器）校验接通开断能力与操作频率
5. 保护电器按保护特性选择
6. 按工作制（8h、不间断、短时、反复短时、周期）选型
7. 特殊要求：互感器符合准确等级

### 6.2 按使用环境
干燥、潮湿、特别潮湿、导电灰尘、化学腐蚀、高温、火灾危险、爆炸危险、室外露天 —— 分别对应开启式/保护式/防尘式/密封式/隔爆型/防爆通风型/充油型/充气型/安全火花型

### 6.3 按短路条件校验
- 动稳定：`Ies ≥ Ich`（额定峰值耐受电流 ≥ 短路冲击电流）
- 热稳定：`It²t ≥ I∞²·tima`

## 七、负荷计算方法（手册1 框架，数值表已损坏）

| 方法 | 适用 | 特点 |
|---|---|---|
| 需用系数法 | 变配电所负荷 | 简便；设备台数少且功率悬殊时偏小，**不适用于低压配电线路** |
| 二项式法 | 低压配电支干线、配电箱 | 考虑大功率设备附加功率，结果偏大 |
| 利用系数法 | 各种范围 | 基于概率统计，最接近实际 |

计算负荷 Pjs = Kx × Pe，Qjs = Pjs × tanφ，Sjs = √(Pjs² + Qjs²)，Ijs = Sjs / (√3 × Un)

**注意**：需要系数 Kx、功率因数 cosφ 的参考值表在本手册中已损坏，需查设计手册或按项目经验取。

## 八、常见坑（结合两本书 + 实际报价）

1. **极数 ≠ 数量**：`3P` 是极数，`1用1备` 才是 2 台
2. **同型号不同附件**：`NSX100N TM100 3P` 与带电动操作机构、分励脱扣是两个价
3. **接触器 AC-3 与 AC-4 不能混用**，重任务用 AC-3 会触头熔焊
4. **热继电器不防短路**，短路保护必须靠断路器或熔断器
5. **熔断器上下级必须差 1~2 级**，否则越级熔断
6. **三角形接法电机的断相保护**，两相结构热继电器无效
7. **按钮颜色有强制规范**，急停必须红色，报价时按图配置不能随意换
8. **互感器变比与内径要同时匹配**开关电流，只对变比不对内径装不进去
9. **铜排按 kg 计价**，按米报价会亏（截面越大差得越多）
10. **抽屉柜 vs 固定柜**价差可达 2~3 倍，报价前必须确认柜型
